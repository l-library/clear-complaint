## 2. 设计原则（负责人已裁定）

1. **叙述层是唯一的自由文本层**。模型的叙述自己解释为什么这个档、自己决定提不提档案（「我看了你的过往记录，你昨天嗓子疼，今天又发烧了，可以认为……」）、自己接住输入里的情绪。不开槽、不定必填板块、不写共情模板。
2. **表单保持表单的诚实**。结论层就长成结论层：档位徽章、科室、候选与逐字引文、就医准备清单。删掉拟人化包装（如伪装成说话的模板句），保留纯信息行（如「建议数日内就诊」）。
3. **闸门管断言，不管文本**。叙述层过断言后校验：命中即整段丢弃降级为纯表单，**绝不裁剪拼接模型文本，绝不换一段预制话顶替**——降级路径是「没有叙述」，不是「假装的人话」。

### 否决记录（勿再提议）

- **否决：确定性解释层**（把 `evidence_idx` 用模板译成「人话」）。理由：本质仍是表单，伪装成人话比诚实表单更糟。
- **否决：情绪通道 / acknowledgment 槽**。理由：仍是给模型行为划格子；输入有情绪时叙述层自然反应即可，不需要专门的地方。

## 3. 架构

```
模型叙述层（唯一自由文本，平台门控之后的呈现节点）
  输入：用户原话（含情绪） · 已验证结论（档位/科室/候选+引文） · history_context · profile_snapshot
  输出：narrative: string — 解释、档案引用、情绪回应都是它的自然行为
  约束：断言后校验（见 N3 四规则）；违规整段丢弃
────────────────────────────
结论表单层（诚实表单）
  档位徽章 · 科室 · 候选情况与逐字引文 · 就医准备清单
  （N1 顺带修：doc_title 展示名映射、删闸门计数、免责合并）
```

可行性依据：Daily-Companion 工作流已在同一平台用同一套 DSL 生成带 `source_refs` 的共情自由文本（`greeting` / `highlights` / `closing`），证明平台能力现成，分诊流只是没开这个槽。

## 5. 叙述节点契约（交平台的接口设计稿）

- **位置**：Triage 工作流门控（citation gate、词表、科室、模板）全部执行**之后**的呈现节点。叙述在已验证结论的下游，不能改动结论。
- **输入**（工作流内部已持有，无需新增请求字段）：用户原话 `complaint_text`、本轮 `answers`、已验证 `draft`（档位/科室/候选及其 `quote`）、`history_context`、`profile_snapshot`。
- **输出**：`narrative: string`，非必填。无枚举、无必填板块、无 acknowledgment 槽。建议长度上限 600 字（中文），超出截断为缺失。
- **失败语义**：呈现节点失败或输出为空时，`narrative` 为 `null`，业务状态与结论完全不受影响——叙述是增益不是依赖。禁止因为叙述失败把 `draft_ready` 变成 `failed`。
- **后端断言后校验（N3 实现方负责，复用现有确定性工具）**：
  1. 词表外病名：叙述中出现的病名必须能被 `vocab.resolve` 折到受控表，且只允许引用最终保留的候选集合；
  2. 表外科室：`departments.contains` 校验，只允许已定科室；
  3. 档位与绝对化措辞：只允许已定档位；「确诊/排除/一定/保证」类措辞 regex 拒绝；
  4. 剂量/处方语：拒绝任何用药剂量、停换药建议（与 `care_guidance` 同规）。
  命中任一 → 整段丢弃、记日志、`narrative=null`，**不裁剪拼接**。
- **幂等**：叙述随结果 `revision` 一起重生成与存储；不参与 `citations_dropped` 等闸门计数；迟到结果仍按既有幂等规则丢弃。

## 6. 风险与缓解

- 叙述重新打开幻觉面 → 断言后校验四规则 + N5 测量兜底（分诊一致率验收线不动）。
- 情绪镜像可能放大痛苦（「你说得对，确实很可怕」）→ 契约写明：回应感受、不确认判断；危机与红旗仍走确定性短路，不经模型。
- 平台联调排期不可控 → N1a / N1b 独立先行，叙述层各阶段不阻塞彼此。
- 叙述质量逐次波动（与 B02 同源，见 issue #44）→ 叙述缺席即降级，不影响结论面；测量轮记录波动幅度。

## 7. 与研究主张的关系

H3 / H4 的创新主张落在输入表示干预（自我归因拆分），不在模板锁；模板锁与词表锁在阶段一是四臂实验的**测量条件**。本计划保留全部可审计机制（引用门、受控词表、科室表、红旗短路），只把「呈现必须模板化」放宽为「断言必须可核查」。N5 的测量把这个放宽的代价显式测出来，对评委的说法是「我们测量了放宽呈现约束的影响」，而非「放弃了约束」。
