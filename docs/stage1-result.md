# 阶段一实验结果

2400 次调用，20 个病例，五个变体，四个实验臂，两个异构模型，三次重复。数据在 `experiment/runs/`，指标与图由 `experiment/analysis/` 从原始记录重算。

## 结论

四个假设里，一个部分成立，三个被否证。

噪声地板是 0.910。同一病例、同一变体、同一臂、同一模型，三次重复之间只有 91% 的档位一致。这个数字是后面所有判断的基准：跨变体的差异只要不明显低于 0.91，就不能算作表述带来的漂移。

只有删减细节越过了噪声地板。基线之下，四个变体与 V1 的档位一致率：V5 拼音 0.92、V3 情绪 0.88、V2 自我诊断暗示 0.87、V4 删减细节 0.68。前三个都在噪声范围内，V4 掉出去 23 个百分点。

漂移集中在判轻那一侧。V4 的 38 次不一致里，28 次判得比基线更轻，其中 16 次落在应当急诊的病例上。其余三个变体略偏保守（净 +3 到 +5）。

## 方法

矩阵是 20 例 × 5 变体 × 4 臂 × 2 模型 × 3 重复。

| 部分 | 设定 |
| --- | --- |
| 模型 | `deepseek-v4.1-flash-1017`（深度求索）、`glm-5.2`（智谱），经华为云 MaaS |
| 采样 | `temperature=0.7`、`top_p=1.0`、`max_tokens=8192`，所有臂一致 |
| 检索 | bge-m3 稠密向量加 2-gram BM25，倒数排名融合，topk=5 |
| 检索池 | 555 条 clinical 片段（临床表现、诊断、重症标准、就医与转诊指征） |
| 受控词表 | 63 个病名，四个臂都给 |
| 统计 | 按病例聚类的 bootstrap，10k 次，报 95% 区间，不报 p 值 |

四个臂只差五条约束的开关。检索池、JSON 轮廓、受控词表在四个臂里完全相同，它们属于测量设施，四个臂共用。

红旗漏检的分母取金标准。若用检测结果当分母，检测失败的那一格根本不进分母，指标恒为零。

## 主结果

配对子集：四个臂都给出合法档位的 422 个单元。用配对子集是为了消掉澄清造成的选择偏倚。

| 臂 | 档位一致率 | 科室一致率 |
| --- | --- | --- |
| A0 裸提示词 | 0.894 | 0.817 |
| Aout 输出侧 | 0.923 | 0.798 |
| Ain 输入侧 | 0.865 | 0.740 |
| Aall 五条全开 | 0.942 | 0.827 |

全样本（含澄清与短路的单元）上的数字：

| 臂 | 模型 | 有效率 | 档位一致率（95% CI） | 科室一致率 | 红旗漏检 |
| --- | --- | --- | --- | --- | --- |
| A0 | deepseek | 1.00 | 0.86 [0.76, 0.95] | 0.82 | 0.33 |
| A0 | glm | 0.99 | 0.81 [0.69, 0.90] | 0.72 | 0.36 |
| Aout | deepseek | 0.99 | 0.83 [0.74, 0.92] | 0.77 | 0.35 |
| Aout | glm | 1.00 | 0.89 [0.82, 0.95] | 0.71 | 0.43 |
| Ain | deepseek | 1.00 | 0.81 [0.69, 0.93] | 0.80 | 0.32 |
| Ain | glm | 0.99 | 0.86 [0.78, 0.94] | 0.60 | 0.37 |
| Aall | deepseek | 0.71 | 0.92 [0.76, 1.00] | 0.87 | 0.20 |
| Aall | glm | 0.72 | 0.96 [0.92, 1.00] | 0.79 | 0.20 |

Aall 的有效率只有 0.71，因为澄清先行把 29% 的单元挡在了结论之外。所以它的高一致率有一部分是样本被筛掉的结果，配对子集那一栏才是可比的。

## 四个假设

H1 部分成立。表述确实会带动档位，但只有删减细节这一族超出了噪声地板。同义改写、情绪、拼音、自我诊断暗示四族的漂移都在 0.87 到 0.92 之间，与 0.91 的噪声地板无法区分。

H2 被否证。预设是自我诊断暗示诱导的漂移最强。实测最强的是删减细节（0.68），自我诊断暗示只有 0.87，与情绪、拼音同处噪声区。把 V2 改成错配的归因（"我以为是过敏性鼻炎，吃了抗过敏药也没用"这种与症状冲突的解释）之后，一致率反而升到 0.93，模型按症状证据判断，不理会用户的解释。

H3 被否证。输入侧摘除归因没有跑赢输出侧提示词。配对子集上 Aout 0.923、Ain 0.865，全样本上两个模型的排序也不一致（deepseek 上 Aout 0.83 对 Ain 0.81，glm 上 Aout 0.89 对 Ain 0.86）。Ain 在科室一致率上更低，0.740 对 Aout 的 0.798。

H4 被否证。两个模型的漂移不同步：跨变体的 57 处偏离里，只有 13 处是两个模型同时出现的，其余 44 处各自发生。约束的效果随模型而变，谈不上模型无关。

## 五个值得单独记的现象

判轻是方向性的。裸提示词下 V4 的 38 次不一致里 28 次低判，16 次落在金标准为急诊的病例上（D05 慢阻肺气促、D06 腹泻脱水、D10 意识改变、P04 胸痛）。图在 `analysis/figures/downgrade.png`。这条比一致率 0.68 有分量，它指出的是错在方向。

确定性规则必须处理否定。规则原本是纯子串匹配，"没有胸痛"命中胸痛规则，"会不会脱水"命中脱水规则。在 Aall 的 600 个单元里，132 次命中中有 18 次是这么来的。加了六字的否定与假设作用域之后，误报 18 降到 0，真阳性 114 保持 114。中途掉过 6 个真阳性，原因是"尿都少了"这个真实信号没有对应的触发词，补上之后恢复。这一段可以写成工程贡献：规则要在不咨询模型的前提下保持安全，就得有确定性的否定作用域。

信息不足时模型退到泛化科室。V4 单元里"全科医学科"占 26%，V1 只有 12%，V3 是 9%。这是科室一致率普遍低于档位一致率的原因之一，也是产品层面的问题：用户拿到"去全科"等于没拿到建议。

候选集合的自由度没人管。与 V1 相比的候选集合 Jaccard 均值，A0 0.50、Aout 0.48、Ain 0.49、Aall 0.49。四个臂没有差别，而且只有 0.50。同一病例换个说法，模型给出的可能相关情况换掉一半。五条约束管的是引用是否合法，不管选哪些情况。

拼音归一化是唯一拿到正面证据的约束。V5 一致率 0.92，与噪声地板持平，说明确定性归一把拼音与错别字折回了可判别的文本。这是五条约束里唯一能在数据上说"有效"的一条。

## 红旗

Aall 的 150 个急诊单元里，114 个的文本含规则认得的措辞，命中后 114 次全部判成急诊，误报 0 次。未命中的 36 个里 30 个进了澄清、6 个交给模型。

所以"Aall 的红旗漏检为零"这句话成立，但必须带上分母：它成立在规则可识别的 76% 的急诊文本上。剩下 24% 没有可识别信号，问题出在规则覆盖上，管线本身没有出错。

先前版本把这个指标算成 0.20 到 0.43，原因有两个：分母用检测结果而非金标准，以及把不跑检测的三个臂也算进了分母。

## 已知限制

澄清先行造成的选择偏倚已经用配对子集处理，但 Aall 的有效率 0.71 是真实代价：一个把三成问诊挡在结论外的产品，在答辩里必须解释。

触发词表覆盖不到全部真实说法。20 例的急诊文本里能识别 76%，扩表前是 16%。未命中的多是 V4：删掉细节之后本来就剩不下可识别的信号。

训练集外的病种没有语料。九个病种域来自国家卫生健康委的公开诊疗方案，头痛、失眠、腰痛一类的症状级指南由中华医学会发布、全文在付费库，既不能入库也不能逐字公开引用。

金标准由三名工科生基于公开指南合议得出，并非临床标注。材料里需要原话写明这一点。

`max_tokens=8192` 对 deepseek 仍然偏紧：2400 个单元里有 11 个因推理占满预算而 JSON 截断，占 0.5%，按约定计为 parse_error 不重跑。

## 复现

```bash
cd experiment
uv run python -m tools.run_matrix --cases pilot --arms A0,Aout,Ain,Aall --reps 3 --models 2 --workers 6 --tag full
uv run python -m tools.run_matrix --cases drafts --arms A0,Aout,Ain,Aall --reps 3 --models 2 --workers 6 --tag full
uv run python -m analysis.metrics runs/*.jsonl
uv run python -m analysis.figures runs/*.jsonl
```

分析层按 `unit_id` 去重，后给的文件覆盖先给的。部分变体重跑过，所以 `runs/` 下同一单元可能有新旧两条记录。
