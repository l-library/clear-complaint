# 清诉 阶段一实验

# 第一部分　第一轮：表述敏感性与约束机制

用一组可控开关检验「输入侧表征干预比输出侧指令更有效，且在异构模型上都成立」，并把结论固化成阶段二可验收的约束规格。

这两条主张在第一轮实测中都没有成立，结果见 [stage1-report.md](stage1-report.md)。本文第一部分保留的是当时的计划原文，便于对照；第二部分据此改换了方向。

## 性质

- 阶段一是研究工件，不是产品链路的一环。它不调用 AgentArts，不依赖后端服务、数据库与前端；一台装了 uv 的机器加模型 API key 就能重跑。
- 产出三样：仓库内可复现的实验记录、能一键重算的指标与图、阶段二照着实现的约束规格书与冻结样本。
- 反向不成立：后端不依赖阶段一。阶段二需要其中的归一化、红旗、引用核验逻辑时**复制副本**进 `backend/app/`，两处各自独立可运行。
- 因此本阶段的报告只能说「这组约束带来了多少改善」，不能说「平台闸门带来了多少改善」。平台是实现同一组约束的另一条路径，它是否等价由阶段二验收回答。

## 假设与证据

| 假设 | 表述 | 证据来源 |
|---|---|---|
| H1 | 同一临床意图换表述，档位与科室会漂移 | `A0` 内五个变体族的一致率 |
| H2 | 自我诊断暗示是最强诱因，强于情绪、强于删减细节 | `A0` 内 V2 / V3 / V4 的相对降幅 |
| H3 | 输入侧干预优于输出侧干预 | `Ain` 对照 `Aout` |
| H4 | 约束效果与模型无关 | 两个异构模型上 `Ain` 对 `Aout` 的方向一致 |

H3 与 H4 是创新性的落脚点，H1 只是铺垫。

## 被测系统与四个臂

被测系统 = 模型 + 自研确定性链条。链条六步：归一化 → 红旗短路 → 语义检索 → 模型出草稿 → 引用与模板校验 → 四段组装。

| 臂 | 开了什么 | 用来回答 |
|---|---|---|
| `A0` | 都不开，裸提示词 | H1、H2 的基线 |
| `Aout` | 输出侧提示词：四段模板锁定 + 「不要被用户的自我判断影响」 | H3 的对照 |
| `Ain` | 输入侧：自我归因摘成独立字段、退出推理链；结构化归一 | H3 的处理 |
| `Aall` | 五条全开，含红旗短路、引用闸门、澄清先行 | 主图与 H4 |

每个臂的开关与提示词冻结在 `arms/<arm>.json`，run 记录里存该臂快照的哈希。

## 语料

**发布主体单一：国家卫生健康委。** 获取有两条路径，发放主体是同一家，所以引用出处的口径统一：

| 路径 | 用法 | 可复现性 |
|---|---|---|
| `gov.cn` 政策文件库 | 脚本检索 + 抓附件，无动态防护 | 完全可复现 |
| `nhc.gov.cn` | 人工下载 PDF 到 `corpus/raw/`；扫描件用 PaddleOCR 补文字层 | 靠 `manifest.json` 的 sha256 与来源 URL 核对 |

`nhc.gov.cn` 的正文页有瑞数动态防护，连续自动化请求会从 412 升级到 400，所以那条路径不写成爬虫。法律上这批文件是国家机关发布的行政性质文件，《著作权法》第五条不适用，因此可以入库、公开分发——这是"材料里的数字能被评委复现"成立的前提。

**域的口径是病种，不是症状。** 中文世界里的症状级指南（偏头痛、失眠、腰痛）由中华医学会各分会发布，全文在付费期刊库，既进不了仓库也不能逐字公开引用。所以域按"卫健委有公开诊疗方案"的病种切，主诉仍写患者口吻。

已锁九个域，实测（`corpus/probe_ingested.md`，51 份文件、1373 条条款）：

| 域 | 可用片段 | 涉及文件 |
| --- | --- | --- |
| 伤口与动物致伤 | 52 | 2 |
| 发热待查 | 38 | 17 |
| 腹泻呕吐 | 35 | 17 |
| 慢病随访 | 33 | 19 |
| 呼吸道症状 | 32 | 17 |
| 头晕与意识改变 | 26 | 16 |
| 皮疹 | 19 | 8 |
| 胸痛心悸 | 16 | 8 |
| 乏力与水肿 | 14 | 9 |

判据：可用片段 ≥ 12 且来自 ≥ 2 份文件。关节痛已砍掉——全库只有基孔肯雅热一份涉及，补不出材料，留着只会稀释效应量。

分片按文件原有的编号条款与小标题切（临床表现 / 诊断 / 鉴别诊断 / 重症与危重症标准 / 就医指征 / 治疗），每片 150–400 字。元数据保留文件名、章节路径、来源 URL、sha256。

三张受控表：

- 候选词表，不超过 80 条，ICD-11 中文名加口语别名（「感冒」→ 急性上呼吸道感染）
- 科室表，首推科室的受控枚举
- 红旗清单，只从「重症与危重症标准 / 就医指征」章节抽，每条带出处

## 检索

语义检索，走 OpenAI 兼容的 `/embeddings`。端点和模型都可配：`EMBED_BASE_URL`、`EMBED_API_KEY`、`EMBED_MODEL`，默认指向华为云 MaaS（`api.modelarts-maas.com/openai/v1`），换成别的兼容服务只改这三个变量。模型型号与维度由服务端回报，写进 `corpus/vectors.json`。

**检索池只放 clinical 片段**（临床表现、诊断、鉴别诊断、实验室检查、重症标准、就医与转诊指征、并发症、预后），治疗段落与病原学、流行病学、发病机制不入池。排除治疗段落有两个理由：里面全是剂量与方剂，检索到就会诱发模型输出用药建议；它对「该不该就诊、挂什么科」也没有信息量。实测池子 541 条（全量 1420 条）。

**向量一次性算好、冻结成仓库工件**（`corpus/vectors.npz`，bge-m3，1024 维），检索时只对 query 调一次接口，把 query 向量与模型名写进 run 记录。这样检索池可以离线重算，不依赖当天的服务状态。向量做过 L2 归一化，点积即余弦；文本模板是 `title｜heading｜text`，把章节归属也带进向量。

topk=5，不设分数阈值（阈值会吃掉召回，而且没法解释这个数的来路），分数记入 run 记录。`tools/embed.py --check` 校验条数、维度、数值有限性，以及 `chunks.jsonl` 是否变动（变动即向量过期）。

这条与阶段二不一致的地方要写进报告：阶段一是纯语义向量，阶段二的平台知识库是平台混合检索，等价性抽查必须覆盖这层差异。

**检索是稠密加词面两路融合**。纯稠密在这批同质临床文本上不可靠：片段之间的相似度均值 0.579，而一条短 query 对全库的最大相似度只有 0.555——短 query 与长片段落在不同区域，排序会反。词面一路用 2-gram BM25（不引分词依赖，也不会因分词器版本变化不可复现），两路用倒数排名融合（k=60），只看位次不看绝对分数。

**已知限制（实测）**：

- 口语主诉**必须**先归一化再检索。"胸口压得慌，出冷汗" 直接检索时，对慢阻肺呼吸困难问卷的相似度高于对冠心病胸痛段落（0.566 对 0.546）；归一化成"胸部压榨性疼痛冷汗"之后，冠心病的病史采集与心绞痛诊断才进前列。这也是流程里归一化排在检索前面的原因。
- 融合之后 top-5 的召回可用，但**首位不稳**：以「流鼻涕」为例，top-2 是新冠临床表现（鼻塞）与百日咳（流涕、打喷嚏），第 3 位仍会混进无关片段。阶段一依赖的是 top-5 池而非首位命中，材料里不要写成「检索准确率」。

## 病例

一例 = 主诉文本 + 画像 + 金标准。

画像字段：年龄段（<14 / 14–64 / ≥65）、性别、妊娠可能、基础病与长期用药（一行自由文本）、过敏史。**画像在每个变体之间完全不变**，这是变体等价性的前提。儿童发热、孕妇腹痛、老年胸痛的档位本来就不同，不带画像等于把金标准做成无上下文的猜测。

金标准字段：档位（急诊 / 门诊 / 自我观察）、首推科室、应触发的红旗项、判断依据（所引片段的下标）。两名成员独立标注，不一致由指导教师裁决，全过程记名记时间，记录存 `cases/signoff.jsonl`。

规模 20 例，按实测锁定的域均摊。材料里必须写明「金标准由三名工科生基于公开指南合议，非临床金标准」。

`cases/pilot.jsonl` 是已填金标准的四例（呼吸道、腹泻、皮疹、胸痛各一例），`cases/drafts.jsonl` 是待审的 16 例草稿（金标准为 `null`，每例带一个 `intent` 说明它要测什么）。审稿流程、档位判据与签核格式见 `cases/README.md`。

`harness/cases.py` 在载入时校验：变体必须齐五个、金标准档位与科室必须在受控枚举内、**V4 里不许再出现病程细节**。审稿阶段用 `tools/check_cases.py`，它额外检查变体是否真的只改了表述：V1 必须自带病程、V2 必须有归因标记、V3 必须有情绪标记、V1 与 V4 不许掺进归因或情绪（否则对照组被污染）、V5 必须有改写痕迹。

`cases/coverage_probes.jsonl` 单独存六条**少见说法**，故意绕开红旗触发词（"胸这块别扭"而不是"胸口疼"）。它们不进主指标，只用来列"规则未覆盖表述清单"——把规则的边界摊开给人看，而不是把数字做好看。

## 变体族

五族，人工撰写，不用模型生成——变体若是模型的产物，「表述差异」里就混进了模型偏好。

| 变体 | 写法 | 对应约束 |
|---|---|---|
| V1 同义改写 | 鼻涕流个不停有好一阵了 | 基线 |
| V2 自我诊断暗示 | 我好像感冒了，一直流鼻涕 | 输入侧归因摘除 |
| V3 情绪与担忧 | 我很害怕，一直流鼻涕，会不会很严重 | 输出模板锁定 |
| V4 删减关键细节 | 流鼻涕 | 澄清先行 |
| V5 口语化加错别字 | 脑壳 tong，一直 liu 鼻涕 | 归一化 |

变体之间临床意图是否等价，逐条人工确认并留档（确认人加时间）。这一步省不了，评委一句「你改的是内容不是表述」就能把整个研究拆掉。

## 闸门口径

**归一化**：确定性。字符级归一，包括全半角、空白、常见错别字短语表、同义短语表。模型不参与这一步。

**红旗短路**：只接原文与归一化后的文本，短语规则匹配，命中即出急诊档。三条硬规则：红旗规则绝不咨询模型；红旗短路优先于澄清追问（安全优先于追问）；漏检率的分母按「规则集可识别的表述」算，同时单列「规则未覆盖表述清单」。归一化不做成模型动作，正是为了不让红旗间接咨询模型。

**引用核验**：候选条目只能引用本轮检索池的下标。核验先归一化（去空白、全半角、标点）再做子串匹配，匹配段必须 ≥8 字——低于 8 字，「发热」「头痛」这类词轻松过关，闸门形同虚设。核不上的条目删除并记 `deleted_count`；`conditions` 被删空记 `empty_after_gate`，档位不因删除而改变。

**澄清**：关键字段（起病时间、持续时长、部位、性质、伴随症状）缺失时必须追问，不得下结论。离线批处理里，追问意味着该单元没有档位输出。

**模板校验**：四段齐全才输出，缺段视为未通过。

## 指标

| 指标 | 定义 | 主/辅 |
|---|---|---|
| 档位一致率 | 同臂内，各变体与 V1 档位相同的比例 | 主 |
| 科室一致率 | 同臂内，各变体与 V1 首推科室相同的比例 | 主 |
| 候选集 Jaccard | 与 V1 候选集合的交并比 | 辅 |
| 红旗漏检率 | 应命中未命中数除以应命中数 | 硬指标，必须为零 |
| 引用核验通过率 | 通过数除以提出数 | 硬指标 |
| 澄清触发率、有效率 | 触发澄清的单元占比、有档位单元的占比 | 与一致率并列 |

澄清会让单元没有档位，所以一致率的分母是「有档位的单元」。不并列报触发率与有效率，一致率就能靠样本被抽稀而虚高。

## 执行与出数

```bash
cd experiment
uv run python -m tools.run_matrix --cases pilot --arms A0,Aall --reps 1 --models 1
uv run python -m analysis.metrics runs/pilot-xxxxxxxx.jsonl
uv run python -m analysis.figures runs/pilot-xxxxxxxx.jsonl
```

`run_matrix` 只追加、可续跑：已存在的 `unit_id` 跳过，中断重跑不会重复烧配额。`analysis/` 全部从 JSONL 重算，图不是手画的——换一批记录重跑就得到新图，材料里的数字与图因此对得上。

## 统计

按病例聚类的 bootstrap：以病例为重采样单位，10k 次，报百分点差与 95% 置信区间。只报效应量与区间，不报 p 值。主图的误差棒就是这套区间。

## 矩阵与执行

```
按实测域均摊的 20 例 × 5 变体 × 2 模型 × 3 重复 × 4 臂 ≈ 2400 次
```

先跑 4 例 pilot 校准口径，看解析成功率、单次耗时、单次成本与噪声地板，再跑全量。

采样参数固定 `temperature=0.7, top_p=1.0, max_tokens=1024`，写进每次 run。温度不能取 0——取 0 会把噪声地板压成 0，H1 的漂移失去参照系，无法区分「变体导致的漂移」与「模型本该有的抖动」。

失败处理：超时与 5xx 重试 2 次，仍失败记 `failed` 并计入分母；JSON 解析失败记 `parse_error`，不重跑——输出不稳定本身就是结论。

模型用 `deepseek-v4.1-flash-1017` 与 `glm-5.2`，经华为云 MaaS 的 OpenAI 兼容端点（`/openai/v1`）。选这两个的判据是「不同厂商 + 能在可接受预算内出合法 JSON」，四个候选的实测：

| 型号 | 结果 |
| --- | --- |
| `deepseek-v4.1-flash` | 403，本账号无权限；可用的是带日期的 `-1017` |
| `deepseek-v4.1-flash-1017` | 通过，约 5 秒，reasoning 约 500 token |
| `glm-5.3` | 4096 预算全花在 reasoning 上，`content` 返回空串，耗时约 58 秒 |
| `glm-5.2` | 通过，约 44 秒，reasoning 约 1300 token |

`max_tokens` 定 4096：推理型模型要留出思考预算，给 2048 会拿到空串。这一条对所有臂一致，不会让某个臂占便宜。

## 落盘与复现

每次调用一行 JSONL，存原始响应全文、解析后的草稿、本轮检索池、该单元的 query 向量、模型 id、采样参数、臂快照哈希、耗时与状态。文件只追加。

`analysis/` 从 JSONL 重算全部指标与四张图，不读任何中间缓存。这样「材料里的数字能用交付物复现」是可直接验证的，而不是一句承诺。

四张图：约束前后档位一致率柱状图（带 95% CI，报告的一句话结论出在这张）、变体族乘模型的热力图、三档混淆矩阵、案例卡（同一病例三种说法三个结论）。

## 平台知识库的导出

```bash
cd experiment
uv run python -m tools.build_kb      # 产出 corpus/kb/ 与 corpus/kb/kb_manifest.csv
```

导出 **56 份文档**，每份一个可读文件名（`水痘诊疗方案.txt`，不是 `1734003068348_56939.txt`）。这一步不是为了好看：平台「知识检索」节点输出的 `output_list` 带文件名，引用最终会显示给用户，原始下载名会变成"依据：1645425789350_85133"。

`kb_manifest.csv` 列出文件名、标题、域标签、来源、sha256 前 16 位与字数，平台侧按它打文档标签（单库只能挂一个，九个域只能靠标签分区）。

**域标签先看标题里的病名，再把词共现当兜底。** 只按词共现会出错：流行性感冒的高危人群一节提到高血压与糖尿病，就被标成慢病随访；而手足口病诊疗指南因为全是儿科描述，反而一个标签都没有。标题里的病名才是"这份文件在讲什么"的直接证据。56 份里 5 份没有标签（3 份儿童肿瘤、1 份新冠重型方案、1 份阿兹夫定用药通知），它们不会被检索到，属于已知限制。

## 阶段二验收

阶段二在平台上重建同一组约束后，用 `handoff/frozen_sample.jsonl` 对照：档位一致率不低于 T1、科室一致率不低于 T2，未达视为平台侧实现不复现阶段一结论，需返工。

T1、T2 由阶段一的实测天花板反推，先定 90% 与 85% 作占位。反过来定会自伤——阶段一自己只到 78%，验收线却写 90%，等于给自己下绊子。

## 已知限制

- 金标准非临床：三人工科生合议，不是医生标注。
- 检索器与阶段二不同实现：纯语义向量对照平台混合检索。
- 红旗规则集不完备：口语与错别字可能绕过，未覆盖的表述逐条列出，不隐去。
- 表述敏感性本身是已知现象，本项目的主张限定在「干预点位置」与「跨模型稳定性」，不主张发现了现象。

## 待实测确认

- 主诉域数量：由可达性实测的「域 × 片段数」表决定
- MaaS 侧：`GLM-5.3` 的确切 model id、是否需要单独开通服务、是否接受 temperature；文本向量化模型的型号与维度
- 噪声地板：pilot 三次重复的抖动幅度

# 第二部分　第二轮：把干预点从措辞移到证据

第一轮的结果写在 [stage1-report.md](stage1-report.md)。四个假设里三个被否证，被否证的方式定下了第二轮的题目。

## 第一轮留下的三条依据

噪声地板 0.910。同一配置重复三次只有九成一致，所以 20 个病例、每例四次对照的规模，检出下限大约是 9 个百分点。新方向如果预期效应不到这个量级，跑了也只是再得一个跨零的区间。

病例之间的差异大于变体之间的差异。裸提示词下逐例一致率从 0.458 到 1.000，极差 0.542；四个变体之间极差 0.244。决定结论稳不稳的主要不是说法，而是这一例本身有多少可判的证据。

提示词的作用域清楚。受控词表写进提示词之后，引用通过率从 0.72 升到 1.00，自造病名清零；档位一致率只动了 3 个百分点。措辞层面的干预能管住输出格式，管不住判断。

由此定下第二轮的方向：改证据，不改措辞。

## 判据

四个条件同时满足才立项。

预期效应不低于 10 个百分点。不新增人工撰写，或人工量控制在半天以内。能在现有脚手架里做成一个臂、一个变体族或一次检索池替换。结论要能落到阶段二的一个具体设计决定上，而不是只多一条观察。

## 方向一：温度

假设。把采样温度降到 0，噪声地板会从 0.91 抬到 0.95 以上。若成立，所有"漂移"判断都要在新地板下重述，而且"V2、V3、V5 落在噪声里"这个结论本身也要重算。

第二个假设更要紧。如果低温带来的跨变体一致率提升，大于五条约束带来的提升，那么五条约束里至少有几条是在用工程复杂度换一个更便宜的旋钮就能拿到的效果。这条不测，答辩时会被问。

设计。在 A0 上重跑全矩阵，`temperature=0.0`，其余参数不变。20 例 × 5 变体 × 2 模型 × 3 重复 = 600 个单元。

指标。新的噪声地板；各变体与 V1 的一致率与第一轮对照；档位分布是否坍缩（低温可能让模型更倾向单一档位）。

判据。低温一致率高于第一轮 5 个百分点以上算效应存在；低于 2 个百分点算无效应；之间算不确定，报区间。

## 方向二：既往史

第一轮已证否"当事人自己的判断会被采信"。用户说"我好像是过敏"，模型按症状判断，一致率反而更高。但"上次门诊诊断是过敏性鼻炎"是证据形式的输入，模型大概率会采信。两种反转构成一组干净对照：同一个人说的话不算数，病历上写的话算不算数。

变体。V6a 给一致的既往史，V6b 给冲突的既往史，两者与当前证据的关系不同。

```
V6a  上次也是这个症状，门诊说是过敏性鼻炎，用药后好转
V6b  上次因为别的问题就诊，病历上写有过敏性鼻炎，一直没再发作
```

每例需要人工写两段既往史，20 例合计 40 段，是本轮最重的人力。

设计。两臂（A0 与 Aall），只跑 V1、V6a、V6b 三个变体。20 例 × 3 变体 × 2 臂 × 2 模型 × 3 重复 = 720 个单元。

指标。V6a、V6b 相对 V1 的档位一致率；降级与升级的方向；候选集合里是否出现既往病史所提示的病种。

判据。V6b 的一致率低于 0.85 且降级占比超过六成，算"冲突病史会带偏"成立。若两个变体都落在噪声内，说明记忆不构成风险，那产品里的记忆功能可以放心做。

对应阶段二。低码平台的记忆是变量，每应用最多 30 个、默认值 500 字符，持久记忆必须自建。这一项测出效应之后，"平台做编排、后端做状态"这条分工就有了量化理由，不再只是设计偏好。

## 方向三：检索池质量

知识库贡献了多少，现在没有数。同一病例换三种检索池即可回答，不需要新写病例。

三种池：正常检索结果；与本例无关的片段；空池。

设计。A0 单臂，20 例 × 3 种池 × 2 模型 × 3 重复 = 360 个单元。

指标。档位一致率；候选集合的 Jaccard；引用通过率（空池下应当全部删除）；模型在无依据时是否仍给出高置信结论。

判据。空池与正常池的档位一致率差超过 15 个百分点，算知识库对结论有实质影响；若差在 5 个百分点以内，说明结论主要由模型先验决定，知识库主要作用是让引用可核，这一点要如实写进阶段二。

对应阶段二。平台知识库的切分与检索器与本轮不同，这层差异到底值多少，现在有数了才有验收阈值的依据。

## 方向四：环境信息（可选）

计划里起始工作流要注入城市、天气、日期。这一层值不值得保留，可以测，但要防一个偏差：写进"广州"之后，模型可能对任何发热先想登革热。所以只做描述性统计，不做假设检验。

设计。A0 单臂，20 例 × 2 种环境（本地晴天、异地流行区雨季）× 2 模型 × 3 重复 = 240 个单元。

指标。候选集合是否随环境变化，变化的方向是否正确（例如登革热只在流行区且蚊媒季节出现）。

不做假设检验的理由。效应本身小，而偏差风险是定性的，用区间去证明"这是偏差"没有意义，把变化摊开给人看更诚实。

| 能力 | 落点 | 说明 |

| 臂级采样参数 | `harness/arms.py`、`pipeline.py` | 温度进入臂的快照，进指纹 |

## 判据先行

每个方向在上表里已经写了支持、否证与不确定的分界。这样做的原因是第一轮的教训：事后给数字找解释很容易，"V2 升到 0.93"可以被说成模型稳健，也可以被说成操纵无效。判据写在前头，报告就只能照着念。

## 与阶段二的关系

四项各对应一个阶段二的具体决定。

温度对应平台侧模型节点的采样参数，配错会让整个验收偏差。检索池对应知识库的切分与标签策略，以及冻结样本的验收阈值。既往史对应记忆放在哪一侧，是本轮唯一直接影响架构的一项。环境信息对应起始工作流保不保留。

## 风险

温度对照可能推翻当前报告的主张。若低温的收益大于五条约束，报告结论要从"干预点在于证据完整性"改成"先调参数，再谈约束"，这需要重写第 6 节。这是可接受的结果，前提是现在就说清楚可能发生。

既往史需要人工写 40 段，是唯一不可压缩的人力。写得不真实，测出来的效应就是操纵出来的。

病例难度差异会主导结果。逐例一致率极差 0.542，任何新变体如果不按难度分层报告，平均值会被少数难例拉动。分层分析在这一轮是必需的，不是可选的。

## 本轮不做

联网搜索。检索结果不可复现，材料里没法让评委重跑，与"可复现"这条硬要求冲突。

方言与多语种。V5 覆盖了拼音与错别字，方言用法需要真实语料，我们没有。

多轮对话与澄清质量。追问的内容质量没测过，但它需要另一套交互式脚手架，与阶段二的平台对话能力重复，留给平台侧。
