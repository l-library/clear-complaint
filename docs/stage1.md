# 清诉 阶段一实验

阶段一是一个研究工件：不依赖后端与平台，一台装了 uv 的机器加模型 API key 就能重跑。产出是仓库内的实验记录、可离线重算的指标与图，以及给阶段二照着实现的约束规格。

结论一句话：证据多少决定分诊的稳定性，表述方式影响很小。画像背景在金标准随条件变化时被正确使用；自我观察档几乎不被使用，是当前最大的误差源。

## 性质与边界

- 被测系统是自写的确定性链条加模型直连，平台在阶段二实现同一组约束
- 结论只算这组约束带来多少改善，不给平台单独归因
- 后端不依赖本阶段；阶段二需要归一化、红旗、引用核验逻辑时，复制进 `backend/app/`

## 语料

单一发布主体：国家卫生健康委的公开诊疗方案。这类行政性质文件不受著作权限制，可以入库分发，这是「材料里的数字能被复现」的前提。共 54 份文件、1470 条片段。

九个病种域，按病种而非症状切：发热待查、呼吸道症状、腹泻呕吐、皮疹、胸痛心悸、头晕与意识改变、乏力与水肿、伤口与动物致伤、慢病随访。症状级指南（偏头痛、失眠、腰痛）由学会发布、全文在付费库，不能入库。

| 项 | 规格 |
| --- | --- |
| 检索池 | 564 条片段：clinical 555 条 + triage 判据 9 条（就医指征与人群判据，受控表 `corpus/triage_pool.json`） |
| 排除 | 治疗段落 533 条（占 36%）；就医指征与人群判据类例外入 triage 受控表 |
| 检索 | bge-m3 稠密向量 + 2-gram BM25，倒数排名融合，topk 5，向量冻结入库 |

三张受控表，每条都能在语料里指到原文，指不到的不写入：

| 表 | 规模 | 用途 |
| --- | --- | --- |
| 红旗清单 | 16 条 | 命中即急诊，引文取自「重症与危重症标准 / 就医指征」章节 |
| 候选词表 | 63 条 | 「可能相关情况」只能从这里选 |
| 科室表 | 17 个 | 首诊科室只能从这里选 |

## 病例

20 个合成病例，九个域全覆盖，每例五个变体。不含任何真实患者信息。

画像字段：年龄段（<14 / 14–64 / ≥65）、性别、妊娠可能、基础病与长期用药、过敏史。画像在各变体之间完全一致，且随提示词一起传给模型。

金标准：档位、首诊科室、应触发的红旗项。两人独立标注、第三人裁决，记名记时间。材料里必须写明「三名工科生基于公开指南合议，非临床标注」。

档位判据先统一再标注：红旗命中为急诊；无红旗但需医生评估为门诊；症状轻微可自限、一周内复评为自我观察。

另有六族二十例条件翻转病例（`cases/families.jsonl`）：同一句主诉，只换画像背景（高危 / 基线 / 无关对照），金标准随条件变化。每例另标就医时限（立即 / 24~48 小时内 / 数天内 / 无需就医），时限是标注层维度，不进产品契约与主指标。复评材料另存 `cases/followup_scripts.jsonl`（六族 base 条件 × 好转 / 不变 / 恶化四方向，红旗预期逐条预检）。

## 测过的全部因素

| 因素 | 条件 | 结果 |
| --- | --- | --- |
| 表述改写 | V1 书面基线、V2 错配自我诊断、V3 情绪、V4 删病程与部位、V5 拼音错别字 | V4 明确越线，V5 也越线，V2 压线且偏保守，V3 落在噪声内 |
| 约束组合 | A0 裸提示词、Aout 输出侧提示词、Ain 输入侧归因摘除、Aall 五条全开 | 约束有效；输入侧不优于输出侧 |
| 采样温度 | 0.7 / 0.0 | 无效应（1.3 个百分点） |
| 检索依据 | 正常 / 无关片段 / 空池 | 强效应，错误的依据比没有更糟 |
| 背景信息（画像与既往史） | 同一主诉 × 高危 / 基线 / 无关对照的条件族 | 模型会用背景：凡 base 答成自我观察的配对，hi 一律升回门诊（12/12）；卡点是自我观察档使用率仅 6% |
| 生命体征 | 与症状同向 / 反向 | 条件未生效，无数据 |
| 随访复评 | 好转 / 不变 / 恶化（无红旗 / 带红旗） | 红旗恶化 36/36 短路升级；好转承认率 72–83%；非红旗恶化与不变区分不出；维持靠规则 |

矩阵为 20 例 × 条件 × 4 臂 × 2 模型（DeepSeek-V4.1-Flash、GLM-5.3-Flash）× 3 次重复，累计 7680 次调用。条件翻转族另有 480 次调用（20 例 × V1 × 4 臂 × 2 模型 × 3 重复），复评另有 288 次（6 族 × 4 方向 × 2 臂 × 2 模型 × 3 重复）。重复三次用来估噪声：同一配置三次结果之间的相互一致率就是噪声地板，实测 0.901。低于 9 个百分点的差异，这个样本规模看不见。

## 结果

### 删减信息掉得最重

裸提示词下各变体与基线的一致率：

| 变体 | 一致率 | 升 / 降 |
| --- | --- | --- |
| V3 情绪 | 0.898 | 9 / 3 |
| V2 错配归因 | 0.817 | 17 / 5 |
| V5 拼音 | 0.800 | 17 / 7 |
| V4 删病程与部位 | 0.683 | 4 / 34 |

按 9 个百分点的检出下限衡量：V4 差 21.8 个百分点，明确越线；V5 差 10.1 个百分点，也在线外；V2 差 8.4 个百分点，压在线上；V3 落在噪声内。

V4 的错误有方向：38 次不一致里 28 次判得比基线更轻，16 次落在金标准为急诊的病例上（慢阻肺气促、腹泻伴少尿、老年意识改变、持续胸痛）。V2 与 V5 的位移偏保守。

### 约束有效，输入侧不占优

四臂都给出合法档位的 781 个单元：

| 臂 | 档位一致率 | 科室一致率 |
| --- | --- | --- |
| A0 裸提示词 | 0.808 | 0.750 |
| Aout 输出侧提示词 | 0.894 | 0.788 |
| Ain 输入侧归因摘除 | 0.875 | 0.788 |
| Aall 五条全开 | 0.913 | 0.827 |

三个约束臂都明显高于裸提示词，两个模型的排序一致：Aout 不低于 Ain。Aall 数字最高，但澄清先行把 18% 的请求挡在结论之外，配对子集才可比。

### 证据层面的干预效应最大

同一批主诉换检索池：

| 对照 | 档位一致率 | 候选集合 Jaccard |
| --- | --- | --- |
| 正常 | — | 0.50（变体之间） |
| 无关片段 | 0.832 | 0.14 |
| 空池 | 0.857 | 0.16 |

换掉依据之后，候选集合的稳定性从 0.50 崩到 0.14。作为对照，五种表述改写的候选集合 Jaccard 都在 0.48 到 0.50 之间，四个臂无差别。

错误的依据比没有依据更糟：无关池 0.832 低于空池 0.857，且分布往轻判方向移动，自我观察从 3 格升到 14 格（空池只到 5 格）。科室稳定性的排序相反，空池更差。

### 画像背景用得上

条件翻转族：同一句主诉只换画像背景，档位金标准随条件变化。六族二十例，4 臂 × 2 模型 × 3 重复，480 格。

模型会用背景。凡 base 条件被答成自我观察的配对，对应的 hi 条件一律升回门诊，12/12。免疫抑制儿童的水痘（F02D）更激进：两个模型四个臂上 18/24 直接判急诊，而金标准是门诊加「立即」时限。三档装不下的紧迫度，模型用跳档表达。

翻转到位率只有 0.00–0.17，原因在下一节：模型几乎不往自我观察档走，翻级只能在它肯下去的少数单元里发生。臂间翻转差异低于检出下限，四个约束臂不作主张。

两个对照都干净。无关背景的零孪生 13–18/18 一致，翻转不是提示词区块的伪影；base 错答按时限交叉联读，全部落在「无需就医」档，属模型保守，不属边界模糊。

生命体征的同向 / 反向条件未生效，无数据。

### 自我观察档是主要误差源

第一轮 2400 个单元里模型只给出 77 次自我观察，金标准要求 720 次；条件翻转族里 base 侧使用率也只有 6%。模型面对轻症倾向答「去看医生」，背景翻转全部发生在它肯下到自我观察档的那些单元里。这一档要靠随访机制补，提示词解决不了；补上之后的实测见下一节。

### 复评接住自我观察档

观察档按流程交付：轻症无红旗进观察，复评定时重跑完整管线。六族 base 条件 × 四方向，2 臂 × 2 模型 × 3 重复，288 格。

- 恶化带红旗：全约束臂 36/36 短路判急诊，模型零参与。裸提示词臂只有 12/18、13/18 答急诊，确定性层的贡献是 0.28–0.33
- 好转：自我观察承认率 72–83%，对照入口的 6%。急性自限族 100%（F01/F03/F04）或 67%（F02/F05）；慢病随访族只有 25%，血压降到一百三、八五模型仍建议复诊，慢病的保守说得通
- 恶化无红旗：升级率 100%，但与不变方向的差值只有 +0.00～+0.11，低于检出下限。升级成立，归因说不通：模型本来就答门诊，地板穿上了升级的外衣
- 不变：89–100% 答门诊。观察窗口未满时的维持不能靠模型，靠计时规则

分工清楚了：进观察靠规则路由，留观察靠窗口计时，升级靠红旗短路；模型在复评里管承认好转与参考意见。四项干预里只有复评语境把自我观察承认率抬起来。

### 红旗

确定性短路，不咨询模型。210 次命中全部判成急诊，误报 0，命中后无一例外。对急诊文本的覆盖率 87.5%，从最初的 16% 提上来走了两步：把触发词从书面短语扩到日常说法，再给每条触发词加六字的否定与假设作用域。

否定作用域是必须的：「没有胸痛」曾经命中胸痛规则，「会不会脱水」曾经命中脱水规则，132 次命中里 18 次如此。加了窗口之后误报归零、真阳性保持。

### 温度不是替代路径

把采样温度降到 0，噪声地板只从 0.896 升到 0.909，V4 仍然停在 0.68。低温不是那条更便宜的旋钮，约束面对的困难也不来自采样噪声。

## 对阶段二

五条约束的实测结果：

| 约束 | 实测 | 在阶段二的地位 |
| --- | --- | --- |
| 澄清先行 | 唯一有强证据（V4 的 23 个百分点） | 核心卖点 |
| 红旗短路 | 零误报零漏检，覆盖 87.5% | 安全骨架，直接搬 |
| 输入侧归一 | 拼音变体 0.80，唯一有正面数据的措辞干预 | 输入卫生，不作主张 |
| 引用闸门 | 一致性上零效应，2400 格里几乎零删除 | 安全底线，不能说它提效 |
| 输出模板锁定 | 管住格式（自造病名清零），管不住判断（档位只动 3 个百分点） | 输出契约 |

两点负结果，两个模型一致：自我诊断暗示不是最强诱因，V2 压线且方向偏保守；输入侧干预不优于输出侧，Aout 不低于 Ain。

观察档按流程进阶段二：轻症无红旗由规则路由进观察，复评定时重跑完整管线，恶化带红旗走确定性短路。模型侧只托付两件事：承认好转（72–83%）与参考意见；维持与升级都是代码的活。

验收用 `experiment/handoff/frozen_sample.jsonl`（100 条，20 例 × 5 变体，含澄清作为预期结果）。阈值：档位 ≥ 0.85、科室 ≥ 0.75，由阶段一全约束臂自身的配对一致率 0.913 与 0.827 反推。实现依据在 `experiment/handoff/constraints.md`。

待办：把语料里现成的数值判据（呼吸频率 ≥30 次/分、静息血氧 ≤93%、收缩压 <90 mmHg）做成确定性阈值规则。体征进输入后，模型读不读得懂数值就不再重要，覆盖率与安全性都会再上一档。

## 局限

合成病例，非临床样本；金标准为非临床合议。

噪声地板 0.901 是检出下限。生命体征条件未生效，重跑前没有可报的数字。复评脚本是单轮合成材料，未测多轮漂移与失联兑底。

语料限于九个病种域。红旗覆盖率 87.5% 按我们自己的病例集算，真实主诉会更低。

澄清先行的代价是真实的：18% 的请求停在追问，没有结论。

## 复现

```bash
cd experiment
uv sync
uv run python -m tools.run_matrix --cases pilot  --arms A0,Aout,Ain,Aall --reps 3 --models 2 --tag full
uv run python -m tools.run_matrix --cases drafts --arms A0,Aout,Ain,Aall --reps 3 --models 2 --tag full
uv run python -m tools.run_matrix --cases families --variants V1 --arms A0,Aout,Ain,Aall --reps 3 --models 2 --tag full
uv run python -m analysis.metrics runs/*.jsonl
uv run python -m analysis.figures runs/*.jsonl
uv run python -m analysis.families runs/families-*.jsonl
uv run python -m tools.run_followup --arms A0,Aall --reps 3 --models 2 --tag full
uv run python -m analysis.followup runs/followup-*.jsonl runs/families-*.jsonl
```

语料构建：`tools/ingest.py`（抽取）、`tools/fetch_govcn.py`（补齐）、`tools/chunk.py`（切片）、`tools/controlled.py`（受控表）、`tools/triage_pool.py`（分诊判据补充池）、`tools/embed.py`（冻结向量）、`tools/build_kb.py`（导出平台知识库）、`tools/build_handoff.py`（生成冻结样本）。

分析层从 `runs/` 的原始记录重算，图由记录生成。同一 `unit_id` 可能有多条记录（部分条件重跑过），按后者覆盖前者。
