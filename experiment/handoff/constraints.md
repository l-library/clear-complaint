# 阶段一交付：约束规格书

阶段二在 AgentArts 上重建同一组约束时，用这份文档当实现依据，用 `frozen_sample.jsonl` 当验收依据。

规格里每条约束都写了四样东西：触发判据（什么情况下生效）、输入输出变换（做了什么）、可测断言（平台侧怎么判它实现对了）、反例（最容易写错的写法）。末尾附阶段一的实测效应，包括测出来是零的那几条。

## 一、输入侧结构化归一

**触发判据**：每次请求，无条件。

**变换**：原文原样入库，之后任何环节都不改写它。归一化产出两份派生文本：字符级归一（全半角、大小写、空白、标点）与口语归一（在字符级之上再折拼音、错别字、口语词）。自我归因从主诉里摘成独立字段，标记为不可信，不进入推理链。

**可测断言**：

- `脑壳tong，一直liu鼻涕` 归一化后包含「头痛」与「流涕」，且不残留拉丁字母
- 同一输入两次归一化结果完全相同（纯函数）
- 自我归因被摘出后，主诉里不再出现被摘出的病名

**反例**：用模型做归一化。红旗规则跑在归一化结果上，模型参与归一会让「红旗不咨询模型」这条非破坏。归一化必须是确定性的。

**实测效应**：拼音变体（V5）与基线的一致率 0.80–0.92，在所有约束里是唯一接近噪声地板（0.90）的一条。它证明归一化有效，但效应量不足以单独作为卖点。

## 二、澄清先行

**触发判据**：主诉里没有交代病程（无「天 / 周 / 小时 / 分钟 / 半天 / 一下午」这类时间表达）。红旗命中时**不**触发本约束。

**变换**：先追问，不给出档位与科室。追问要问的具体字段是起病时间、持续时长、部位、性质、伴随症状。

**可测断言**：

- 输入 `流鼻涕`（无病程）→ 返回澄清问句，无分诊档
- 输入 `流鼻涕三天了` → 正常给档位
- 红旗病例即使缺病程也不进澄清（安全优先于追问）

**反例**：把追问做成「请补充更多信息」这种泛化提问。要按字段问，否则用户不知道该说什么。

**实测效应**：这是唯一有强证据的约束。删掉病程与部位（V4）让档位一致率从 0.88–0.93 掉到 **0.68**，且 38 次不一致里 28 次判轻、16 次落在应当急诊的病例上。澄清先行把这类单元挡在结论之外，代价是有效率降到 0.82（18% 的请求停在追问）。

## 三、红旗确定性前置

**触发判据**：原文与归一化文本命中任一红旗规则的触发词，且触发词不在否定或假设的作用域内。

**变换**：直接输出急诊档与急诊科，**不调用模型**。

**可测断言**：

- `没有胸痛，心慌两小时` 不命中胸痛规则（否定作用域）
- `会不会脱水` 不命中脱水规则（假设语气）
- `胸口疼，没有缓解，出汗` 命中（否定词在触发词之后，毛病是真的）
- 同一句里有一处未被否定的命中，就算命中
- 命中后档位恒为急诊，与模型输出无关

**反例**：把否定判断交给模型，或者只做子串匹配。阶段一实测：132 次命中里 18 次是「没有胸痛」这类否定表述造成的误报。

**实测效应**：命中 210 次，误报 0，命中后判急诊 210/210。对急诊文本的覆盖率 87.5%，未覆盖的多是删掉细节的变体。**这是五条约束里唯一做到零漏检的**，也是答辩时最该展示的一条。

**待扩展**：语料的重症标准本来以数值书写（呼吸频率 ≥30 次/分、静息血氧 ≤93%、收缩压 <90 mmHg），体征进输入后应把这三条做成确定性阈值判定，覆盖率与安全性都会再上一档。

## 四、引用闸门

**触发判据**：每次产出「可能相关情况」，无条件。

**变换**：候选只能引用本轮检索池的下标；引文必须与池内原文逐字一致（字符级归一后比较，**不折同义词**），匹配段不少于 8 字；核不上的条目删除；删空的结论不出档。

**可测断言**：

- 引文与原文差一个字 → 删除该条
- 引文短于 8 字 → 删除（否则「发热」这种词轻松过关）
- 引文取自别的下标 → 删除（不能借别处的原文担保）
- 下标越界 → 删除，不崩溃
- 全部删除 → 不输出结论

**反例**：把「发烧」折成「发热」再比对。那是逐意核验，不是逐字核验，约束立刻不可证。

**实测效应**：**在一致性上没有任何效应**。全约束臂的引用通过率 0.99–1.00，2400 个单元里几乎零删除——模型照着检索池逐字抄，闸门没有可拦的东西。它是一条安全底线，不是提升稳定性的手段，材料里不能写成「引用闸门提高了准确率」。

## 五、输出模板锁定

**触发判据**：每次输出，无条件。

**变换**：固定四段（分诊档、首推科室、可能相关情况 3–5 条带引用、就医准备清单）。档位必须在三值枚举内，科室必须在 17 个受控科室表内，候选病名必须在 63 条受控词表内。

**可测断言**：

- 缺任一段 → 判不合格
- 档位写成「门诊」这种中文值 → 判不合格（阶段一实测出现过 3 例）
- 科室不在受控表 → 判不合格
- 候选名不在受控词表 → 删该条

**反例**：只校验「四段是否齐全」而不校验取值。阶段一最初就是这样，结果模型的非法档位原样进了统计。

**实测效应**：受控词表进入提示词之后，自造病名从几十条降到 0，引用通过率从 0.72 升到 1.00。**模板锁定管得住输出格式，管不住判断**——同一批单元上，档位一致率只动了 3 个百分点。

## 阶段二验收

用 `frozen_sample.jsonl`（100 条，20 例 × 5 变体）对照平台实现：

| 指标 | 阈值 | 依据 |
| --- | --- | --- |
| 档位与冻结样本一致 | ≥ 0.85 | 阶段一全约束臂在四臂配对子集上的自身一致率是 0.913，实现自身就到不了 1.0 |
| 科室与冻结样本一致 | ≥ 0.75 | 同上，科室一致率 0.827 |
| 红旗命中必为急诊 | 100% | 硬指标，不设容忍度 |
| 澄清触发与冻结样本一致 | ≥ 0.85 | 冻结样本里 28 条的预期是澄清 |

冻结节里 `expected_triage` 为 `clarification` 的条目，平台侧应当同样停在追问，不给出档位。

## 不要照搬的三条主张

阶段一否证了三条流行假设，材料里不要写成正面结论：

1. **自我诊断暗示不是最强诱因**。把它摘走（V2）与基线一致率 0.82–0.93，落在噪声内；真正的最强诱因是删减信息（V4，0.68）。
2. **输入侧干预不优于输出侧**。四臂配对子集上 Aout 0.894 对 Ain 0.875，在两对异构模型上都成立。
3. **既往史与生命体征不改变结论**。安抚型、医嘱型既往史与体征同向、反向四种条件全部落在噪声里，区间跨零。

这三条写成否定，比包装成正面更有说服力：我们否证了什么，以及用什么规模的数据否证的。
